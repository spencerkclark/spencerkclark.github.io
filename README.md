## `spencerkclark.github.io`

This repository contains the code for defining and deploying my website. It is
a fork of the [`astro_academia`
template](https://github.com/maiobarbero/astro_academia) with several custom
modifications.

### Development

Local development can be managed through
[`pixi`](https://pixi.prefix.dev/latest/). To serve the website locally, with
`pixi` installed, run the following command from inside the repository:

```
$ pixi run serve
```

This will install the necessary dependencies and launch the website at
`http://localhost:4321/`.
